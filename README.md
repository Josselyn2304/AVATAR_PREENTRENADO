# 3D Disney/Pixar Style Avatar Generation

## Overview
This project focuses on generating 3D avatars in the popular Disney/Pixar animation style from user-submitted photographs using advanced machine learning techniques.

## Introduction
The goal of this project is to create a machine learning model capable of transforming real-life images into stylized 3D avatars that resemble characters from Disney and Pixar animations. This involves utilizing deep learning techniques, including convolutional neural networks (CNNs) and 3D modeling strategies.

## Features
- Photo-to-3D avatar conversion
- High-quality and stylized avatars
- User-friendly interface
- Fast processing time

## Technologies Used
- Python
- TensorFlow or PyTorch (for model training and inference)
- OpenCV (for image processing)
- Blender (for rendering 3D models)

## Installation
To install the necessary libraries and set up the project environment, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/Josselyn2304/AVATAR_PREENTRENADO.git
   cd AVATAR_PREENTRENADO
   ```
2. Create a virtual environment:
   ```bash
   python -m venv env
   source env/bin/activate # On Windows use `env\Scripts\activate`
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. Run the application:
   ```bash
   python app.py
   ```
2. Upload a photo to convert it into a 3D avatar.
3. Wait for processing and download your generated avatar.
